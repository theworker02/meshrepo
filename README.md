# meshrepo

Mesh identifiers and repo tokens for idempotent workflows.

**Site:** https://theworker02.github.io/meshrepo/

## Install / run

```bash
git clone https://github.com/theworker02/meshrepo.git
cd meshrepo
node src/cli.js
node --test
```
